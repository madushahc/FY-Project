# EduQuest Frontend - Next.js Application

EduQuest is a research-backed learning management system incorporating Points, Badges, Leaderboards (PBL), and behavioral student engagement analytics.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment on Netlify

This application is configured for deployment on **Netlify** with Netlify Serverless Functions.

- Configuration file: `Frontend/netlify.toml`
- Continuous Deployment Workflow: `.github/workflows/deploy-netlify.yml`
